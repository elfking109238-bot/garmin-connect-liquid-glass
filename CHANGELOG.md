# Changelog

## 0.2.1

- Publish the CSS-only Garmin Connect China appearance skin.
- Add soft mint, peach and blue gradients with translucent rounded cards.
- Preserve the original page layout, data, chart colors and controls.
- Remove dark hover corners caused by the original sidebar row background.
- Remove the original dark side borders from the navigation scrollbar thumb.
- Keep active navigation states and a visible keyboard focus outline.
- Limit all extension injection to `https://connectus.garmin.cn/app/*`.

This is the first public release of the locally tested 0.2.1 stylesheet.
